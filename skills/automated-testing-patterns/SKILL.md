# Automated Testing Patterns (Agentic Awesome Skills)

## Core Guidelines
1. **Mathematical Precision Tests:** Test edge conditions, extreme time horizons (e.g. 1000-day compounding), and zero-drift floating-point computations with `Decimal.js`.
2. **DAG & Cycle Detection Tests:** Validate directed acyclic graphs for circular reference protection and recursive depth limits.
3. **Chaos & Load Stress Simulations:** Run concurrent gateway load simulations to verify p95/p99 latencies, pool recovery, and circuit breaker tripping.
4. **Isolated Mocking:** Decouple external third-party API dependencies (e.g. cloud storage, generative models) with deterministic local mocks during testing.
