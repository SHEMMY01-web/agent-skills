# Design Taste Frontend (Agentic Awesome Skills)

## Core Guidelines

### 1. Typography & Readability
- Pair modern sans-serif headings (Inter / Outfit / Plus Jakarta Sans) with crisp monospace metadata tags (`font-mono text-xs uppercase tracking-wider`).
- Line height: Use `leading-relaxed` (1.625) for body text and `leading-tight` (1.25) for bold display titles.

---

### 2. High-Taste Surfaces & Depth
- **Surface Layering:**
  - Base: Soft slate tinted background (`bg-slate-50/60`).
  - Card Layer: Elevated pure white with backdrop filter (`bg-white/90 backdrop-blur-sm border border-slate-200/80`).
  - Accent Callouts: Delicate colored gradients with 4px solid left indicator borders (`border-l-4 border-l-rose-500 bg-rose-50/40`).

---

### 3. Polish Checklist
- [x] Zero raw browser alerts (always use toast notifications).
- [x] Clear empty states with contextual icons and actionable guidance.
- [x] Hover transitions with smooth cubic-bezier easing (`transition-all duration-200 ease-in-out`).
- [x] Accessible color contrast ratios meeting WCAG 2.1 AA standards.
